# Dashboards and Web Analytics

Reviewed: 2026-10-30. Based on visible dashboard controls and public help.

## What Dashboards does

Dashboards brings ongoing metrics together in one place. The current
navigation includes Web Analytics, custom dashboards, and applicable SaaS
reports. A dashboard is useful for regular review; use Analytics when you
want to build or investigate a specific analysis.

## Web Analytics

Use Web Analytics to understand website traffic: visitor and session
activity, page views, acquisition sources, popular pages, locations, and
conversion-goal performance where configured.

1. Open **Dashboards → Web Analytics**.
2. Select a reporting period and the relevant domain or filters offered.
3. Read the headline metrics, then inspect the traffic, source, and page
   summaries that explain them.
4. Open a detailed view or refine the audience to investigate a specific
   source or page. Compare periods where offered.
5. Use a saved view where available to return to a useful filter combination.

Example: compare this month's organic traffic with the preceding period,
then inspect the landing pages attracting those visits. Traffic volume and
conversions answer different questions; a popular page need not be the page
most associated with your chosen outcome.

Public reference: [Web Analytics overview](https://usermaven.com/docs/articles/overview-4e654567).

## Creating a custom dashboard

The current app offers a template-based start or **Build from Scratch**.

1. Open the dashboard creation control.
2. Choose an available template or start from scratch.
3. Give the dashboard a name and optional description. Review who can access
   it using the choices displayed in the creation form.
4. Add relevant analyses. The current dashboard controls include Trends,
   Funnels, Journeys, Retention, and text tiles. Attribution views are also
   supported where offered.
5. Arrange the content using the layout controls, and save changes.
6. Select a consistent reporting period and inspect the tiles together.

Example: an activation dashboard might combine a signup trend, an onboarding
funnel, a return-behavior analysis, and a text tile explaining the activation
definition. Each tile still depends on its own data and configuration.

## Templates and business-specific views

The template chooser includes options such as **SaaS Growth Overview**,
**WooCommerce**, **Google Search Performance**, **AI Traffic**, and
**Subscription Revenue** where applicable. Follow the selected template's
setup prompts; choosing a template does not supply a missing integration.

- **Search performance:** Review search clicks, impressions, queries, and
  landing-page results when the relevant source is connected.
- **AI Traffic:** Review the available summaries of referrals from AI tools
  and recognized crawler activity. These describe different kinds of traffic.
- **Subscription Revenue:** Review billing-based revenue metrics when the
  required source and setup are available. Product activity is not itself
  subscription revenue.

## Ecommerce

For a store, first complete the supported platform integration. Open an
available ecommerce dashboard, select dates, and review recorded sales,
customers, and products. Use a purchase goal and Attribution to investigate
marketing contribution; use a funnel to explore shopping-step completion.

WooCommerce has a dedicated integration and dashboard experience. Other
platforms may require different setup. Confirm the available integration
rather than promising identical automatic tracking for every store.

Public reference: [Ecommerce analytics and attribution](https://usermaven.com/docs/articles/ecommerce-analytics-and-attribution-aac1a432).

## Sharing and reporting

Use the dashboard's **Share** control to review people, workspace access,
and public-link options offered to your role. Review the intended audience
before enabling a share option. For recurring summaries, choose the schedule
report action where available and follow [Reports](reports.md).

This guide describes sharing controls only; it contains no dashboard links
or real workspace results. Exact visibility options vary by dashboard type.
