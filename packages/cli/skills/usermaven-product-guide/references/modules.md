workflows. It contains general product information, not account data or
implementation documentation.

Reviewed on 2026-10-30 using frontend navigation, visible form labels, and
public help. The guide has not been exercised in a live workspace. Some
public articles describe older navigation, especially **Product Insights**;
the current app places SaaS reports under **Dashboards**. Availability and
labels can vary with workspace type, enabled reports, integrations, and
permissions. Describe the controls the user actually sees rather than
promising all features to every account.

Coverage is an introduction to each area, not an exhaustive manual for every
advanced option. Exact plan entitlements, SDK code, API operations, backend
behavior, internal checks, and platform directory packaging are outside this
guide. Public source links are included where available. UI-only descriptions
are limited to observable controls; they do not establish production rollout.
